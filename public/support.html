FAQ

Frequently asked questions

Getting started

What exactly is Zinfai?

A personal finance application you install on your own computer. It tracks everything you own across 40+ asset types and five jurisdictions, keeps prices and FX rates current, builds a FIRE plan, and can generate an AI financial plan using an API key you supply. It runs as a local web app in your browser at http://localhost:8090.

Is it free? Is there a subscription?

Zinfai and Zinfai Buddy are free to download and use. There is no subscription, no account, and no paid tier. The only cost you might incur is your own AI provider's API usage, if you choose to enable the AI features.

Do I need to create an account?

No — not with us. You create a login inside your own copy of the app so the data is protected on your machine, but that account exists only in your local database. Nothing is registered anywhere online.

Which countries and currencies are supported?

India, the United States, the United Kingdom, the UAE and Australia are supported as base locations, each with its own instruments, tax rules, market hours and indices. Individual holdings can be in any currency — the multi-currency engine converts for roll-ups while keeping native amounts intact.

Installing & running

Which platforms can I install on?

macOS (Apple silicon and Intel) and Windows 10/11 have native installers, and there is a Docker image that runs anywhere Docker does, including Linux. Both desktop installers set up Docker for you if it isn't already there. See the download page.

Why does my Mac or Windows say the app is unverified?

Because the installers aren't signed with a paid Apple Developer or Windows code-signing certificate yet. On macOS, right-click the .pkg and choose Open, or use the sudo installer command shown on the download page. On Windows, click More info → Run anyway on the SmartScreen prompt.

The app won't load at localhost:8090.

Check Docker is running, then check the container: docker ps should list zinfai. If it isn't there, start it with docker start zinfai. If it is running but the page won't load, give it 30–60 seconds on first launch while the database initialises, and check the logs with docker logs zinfai. If port 8090 is taken by something else, re-run the container with a different host port, e.g. -p 9090:8080.

How do I update to a new version?

The app shows a banner when a newer release is available. On macOS and Windows, download and run the newer installer — your data volume is preserved. On Docker, pull the new image and recreate the container with the same -v zinfai-data:/var/lib/postgresql/data volume; the exact commands are on the Docker section.

How do I uninstall it completely?

Stop and remove the container (docker rm -f zinfai), then remove the image (docker rmi zinfaiadmin/zinfai). Your data lives in the zinfai-data Docker volume and survives all of that — delete it with docker volume rm zinfai-data only when you're sure, because that erases everything permanently. Export a backup first.

Using the app

Where do prices come from, and how often do they update?

Public market data sources, per exchange: NSE and BSE for Indian equities, the US, London and Australian markets for foreign listings, AMFI for mutual fund NAVs, and public crypto APIs for coins. Prices refresh roughly every 30 minutes while the app is running, and FX rates revalue daily. You can also refresh manually at any time.

A holding isn't picking up a price.

Almost always a symbol mismatch. Open the asset and set the API symbol explicitly — Indian listings need the exchange suffix (RELIANCE.NS, .BO for BSE), London listings .L, Australian .AX. Mutual funds match on their AMFI scheme code. Asset types without a public quote — real estate, PPF, insurance, collectibles — are valued from the numbers you enter, by design.

My bank or broker statement didn't import cleanly.

Zinfai has dedicated parsers for the major Indian banks and brokers and for NSDL/CDSL CAS files. Anything else falls back to AI parsing, which needs an AI provider key configured in Settings. If a statement still comes out wrong, email it to us with the sensitive parts redacted and we'll look at adding a parser — that's how most of them got written.

Do I have to use the AI features?

No. Leave the API keys blank and everything deterministic still works: tracking, supported statement formats, prices, XIRR, snapshots, net worth, alerts and the entire FIRE engine. The AI planner, asset quality ratings, news analysis and fallback statement parsing are the parts that need a key.

Which AI providers can I use?

OpenAI, Anthropic Claude, Google Gemini, xAI Grok, DeepSeek and Mistral. Add your key in Settings (or a local .env) and switch provider whenever you like. Calls go from your machine straight to the provider — they never pass through us.

How do backups work, and how do I move to a new computer?

Settings → Backup exports a single JSON file containing everything: assets, transactions, expenses, income, liabilities, ratings, alerts, planner data and settings. Import it on the new machine and IDs are remapped automatically. You can also enable nightly backup to your own Google Drive — which is the same file Zinfai Buddy reads.

Zinfai Buddy

Can I use Buddy without Zinfai?

No. Buddy has no backend and no way to enter data — it renders a Zinfai backup file. Without one it stops at the onboarding screen. There is no demo mode.

Is Buddy on the Play Store? Is there an iPhone version?

Buddy is distributed as a direct APK from the downloads hub, not the Play Store — see the install steps. There is no iOS version at the moment.

Can Buddy change my data?

It cannot. Buddy is read-only by design: it can display the backup and overlay live prices on top, but it has no code path that writes back to Zinfai.

Privacy & safety

Does any of my financial data leave my machine?

Your holdings, transactions and expenses live in a database on your own computer and are never uploaded to us — we don't run a server that could receive them. Three things do leave, and only if you use them: symbol lookups to public price and FX sources, prompts to the AI provider whose key you configured, and backup files to your own Google Drive if you enable that. Full details in the privacy statement.

Is Zinfai regulated investment advice?

No. Zinfai is a tracking and planning tool for your own research. The AI planner and asset quality ratings are AI-generated and can be wrong. Zinfai is not a registered investment adviser, broker or tax adviser, and nothing in the app is a recommendation to buy or sell. Verify anything important and consider a registered adviser in your own jurisdiction.
